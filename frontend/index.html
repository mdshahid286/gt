The process

From resume to explained verdict

Three mathematically rigorous stages — no black-box scores, no single point of failure.

01

Four agents score independently

Skills, Experience, Education, and Fairness each evaluate the candidate on their own axis. No agent sees another's opinion — preventing groupthink at the source.

02

Nash Bargaining decides

A hire only happens if every agent gains relative to its disagreement point. One well-founded dissent is enough to fall back to reject — unanimous buy-in required.

03

Shapley values explain

Exact Shapley computation (2⁴ = 16 subsets) attributes the decision back to each agent's marginal contribution — real percentages, not post-hoc rationalization.

The panel

Meet the four agents

Each one focuses on a single axis and never sees the others' scores until Fairness reviews their reasoning.

🛠️

Skills

Technical and domain skill match — tools, languages, depth demonstrated through real projects, never keyword matching.

📈

Experience

Relevant work history and career trajectory — never penalises employment gaps by default; flags them for fairness review instead.

🎓

Education

Relevance of academic background to the role — bootcamps and self-taught paths score on merit, not institutional prestige.

⚖️

Fairness

Reviews the other agents' reasoning for proxy signal reliance — never makes its own demographic inference about the candidate.

Under the hood

The math behind the verdict

Pure cooperative game theory — deterministic, auditable, no hidden scoring weights.

Nash

Bargaining equilibrium

Each agent has a disagreement point — its utility if the candidate is rejected. A hire requires every agent to gain above that floor. The weighted Nash product is then maximised.

Shapley

Marginal contribution

For each agent, Shapley computes the average marginal value it adds across all 2⁴ = 16 possible coalitions — answering "without which agent would the outcome have changed?"

Prompt

Injection defence

Every resume is wrapped in delimiters with a reminder placed after the untrusted text — exploiting the recency bias of LLMs to close the injection window.
